# Agent Rules

This directory contains persistent instructions and workflows for AI agents working on this repository.

## Development Rules

1.  **Commit after every feature**: Always stage and commit changes immediately after completing a new feature, bug fix, or significant improvement.
2.  **Descriptive commit messages**: Use clear, concise, and descriptive commit messages that explain *what* and *why*.
3.  **Responsive Design**: Always ensure new UI elements are responsive (mobile-first approach).
4.  **No Affiliate Links**: Never add affiliate links to the Munich guide; maintain it as a pure local resource.
5.  **Selective Browser Media**: Only provide browser screenshots or videos for verification when a change has a significant visual or interactive impact.
    *   **Use media for**: Layout adjustments, CSS/styling changes, new interactive features (maps, modals), or mobile responsiveness checks.
    *   **Skip media for**: Text-only updates, link fixes, SEO/meta tag changes, or internal logic refactors that don't change the UI appearance.
